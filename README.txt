PERSONAL CV / RESUME WEBSITE — SEPARATE FILES

Files:
- index.html  : page content / structure
- style.css   : website design and responsive layout
- script.js   : menu, print CV, footer year, and contact form behaviour

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Replace all sample profile, education, project, and contact information.
4. In script.js, replace "your.email@example.com" with your real email address.

The contact form uses mailto, so it opens the visitor's email application. It does not send messages through a server.
